# Installing Python with Windows PS

1. Start a Windows PS with admin rights
2. Navigate to a your desktop

<img width="657" height="216" alt="2026-10-11_14-41_1" src="https://github.com/user-attachments/assets/437b59fa-5ee6-40cf-bb4a-db9653347b76" />

3. Make a new folder with:

```mkdir python```

4. Navigate to the folder

<img width="1185" height="682" alt="2026-10-11_14-41" src="https://github.com/user-attachments/assets/7328dd11-78ff-414c-bcfa-40e0b695b605" />

5. Use the following PS command

```winget install Python.Python.3.14 ```

6. Wait until the install is complete

7. Congratz you've installed Python through the Windows PS command line!
